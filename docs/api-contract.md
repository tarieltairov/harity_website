# API-контракт «Алтын Мурас» (фронт → бэк)

Контракт публичного API сайта фонда. Источник правды — фронтенд: сущности повторяют `src/types/`, ожидаемые данные — `src/mocks/`. Админ-панель — вне скоупа (отдельная задача), здесь только чтение публичного контента + две формы.

Версия контракта: **v1** · Статус: черновик на согласование

---

## 1. Общие положения

- **Base URL:** `/api/v1`
- **Формат:** JSON, UTF-8. Все ответы — `Content-Type: application/json` (кроме файлов).
- **Аутентификация:** не требуется (публичное API, только чтение + формы). CORS: разрешить домен сайта.
- **Язык контента:** query-параметр `lang` (`ru` | `ky` | `en`), по умолчанию `ru`. Локализуются все текстовые поля. На старте допустимо отдавать только `ru`, но параметр принимать уже сейчас (в патче 2 есть переключатель языка с URL-префиксами `/ru/ /ky/ /en/`).
- **Даты:** ISO 8601 (`2026-07-03`). Форматирование («3 июля 2026») — на фронте.
- **Изображения и файлы:** абсолютные URL. Для документов бэк отдаёт `sizeBytes` и `format` — подпись «PDF · 2.4 МБ» собирает фронт.
- **Идентификаторы:** целые числа (`id`). Поле `slug` заложить в модель на будущее (SEO), в v1 не обязательно.

### Пагинация

Единый конверт для всех списков:

```json
{
  "items": [],
  "page": 1,
  "pageSize": 9,
  "total": 14,
  "totalPages": 2
}
```

- Новости: `pageSize` по умолчанию **9**; результаты поиска — **10** (из макетов).
- «Показать ещё» на мобильных — та же пагинация, фронт докладывает страницы сам.

### Ошибки

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Проверьте правильность заполнения полей",
    "fields": { "email": "Некорректный e-mail" }
  }
}
```

- `400` — ошибка валидации (обязательно `fields` по полям — модалка «Написать нам» показывает ошибки под каждым полем);
- `404` — сущность не найдена (`code: "NOT_FOUND"`);
- `500` — `code: "INTERNAL_ERROR"`, без деталей.

## 2. Сущности

Ниже схемы ответов. `?` — поле может отсутствовать/быть `null`.

### NewsPreview — карточка-ссылка («Популярное», «Читайте также», «Новости проекта»)

```ts
{
  id: number;
  title: string;
  publishedAt: string;
  image: string;
}
```

### NewsListItem — карточка в ленте

```ts
{
  id: number;
  title: string;
  excerpt: string;
  category: {
    slug: string;
    title: string;
  } // slug: projects|reports|events|partnership|press
  publishedAt: string;
  image: string;
}
```

### NewsArticle — деталка (экран 08)

```ts
NewsListItem & {
  imageCaption?: string;
  lead: string;
  body: string[];                               // абзацы
  quote?: { text: string; author: string };
  gallery: string[];                            // URL фото
  documents: DocumentFile[];
  related: NewsPreview[];                       // «Читайте также», бэк отдаёт готовыми (без relatedIds)
}
```

### ProjectListItem / Project — деталка (экран 09)

```ts
{
  id: number;
  title: string;
  excerpt: string;
  status: 'active' | 'completed';
  image: string;
}
// деталка дополнительно:
{
  period?: string;                              // 'март 2024 — сейчас' (готовая строка)
  region?: string;
  lead: string;
  body: string[];
  stats: Array<{ value: string; label: string }>;
  gallery: string[];
  news: NewsPreview[];                          // «Новости проекта»
  supportNote?: string;                         // текст блока «Поддержать проект»
}
```

### DocumentFile

```ts
{
  id: number;
  title: string;
  format: 'PDF' | 'DOCX' | 'PPTX' | 'ZIP';
  sizeBytes: number;
  url: string; // прямая ссылка на скачивание
}
```

### Partner (+ деталка для модалки, экран 13)

```ts
{
  id: number;
  abbr: string;                                 // 'ДА' — плашка-логотип, пока нет логотипов
  logo?: string;                                // URL, когда появятся
  fullName: string;
  kind: 'partner' | 'donor';
  since?: number;                               // год начала сотрудничества
  // только в деталке:
  description?: string;
  website?: string;
  projects: Array<{ id: number; title: string; status: 'active' | 'completed' }>;
}
```

### TeamMember (модалка, экран 13)

```ts
{
  id: number;
  photo: string;
  name: string;
  role: string;
  sinceYear?: number;
  bio?: string;
  responsibilities?: string;
  email?: string;
  languages?: string[];                         // ['кыргызский', 'русский', 'английский']
}
```

### StatItem, Contacts

```ts
{
  value: string;
  label: string;
} // '12 лет' / 'Работы фонда'

{
  address: string;
  phone: string;
  email: string;
  workingHours: string;
  socials: Array<{ label: string; href: string }>;
}
```

## 3. Эндпоинты

### Новости

| Метод | Путь                    | Что делает                                                                                                                                                                |
| ----- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET   | `/news`                 | Лента. Параметры: `category` (slug), `q` (поиск по заголовку), `page`, `pageSize=9`, `lang`. Сортировка: свежие первыми. Конверт пагинации из §1, `items: NewsListItem[]` |
| GET   | `/news/categories`      | `[{ slug, title, count }]` — счётчики для фильтров и сайдбара «Категории». Счётчики глобальные, без учёта `q`                                                             |
| GET   | `/news/popular?limit=3` | `NewsPreview[]` — сайдбар «Популярное» (пока — на усмотрение бэка: по просмотрам или вручную)                                                                             |
| GET   | `/news/{id}`            | `NewsArticle` — деталка. `related` — 3 материала                                                                                                                          |

### Проекты

| Метод | Путь             | Что делает                                                                                                                                              |
| ----- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET   | `/projects`      | Список. Параметры: `status` (`active`\|`completed`), `featured=true` (3 «ключевых» для главной), `page`, `pageSize`, `lang`. `items: ProjectListItem[]` |
| GET   | `/projects/{id}` | `Project` — деталка со `stats`, `gallery`, `news`                                                                                                       |

### Отчёты и документы

| Метод | Путь         | Что делает                                                                       |
| ----- | ------------ | -------------------------------------------------------------------------------- |
| GET   | `/reports`   | Страница «Отчёты»: `[{ year: number, files: DocumentFile[] }]`, годы по убыванию |
| GET   | `/documents` | Блок «Документы фонда» на «О фонде»: `DocumentFile[]`                            |

### Партнёры, команда, фонд

| Метод | Путь             | Что делает                                                             |
| ----- | ---------------- | ---------------------------------------------------------------------- |
| GET   | `/partners`      | `Partner[]` без `description/website/projects` (список карточек)       |
| GET   | `/partners/{id}` | Полный `Partner` для модалки                                           |
| GET   | `/team`          | `TeamMember[]` — полные объекты (модалка открывается без доп. запроса) |
| GET   | `/stats`         | `StatItem[]` — цифры фонда (hero главной и «О фонде»)                  |
| GET   | `/contacts`      | `Contacts` — страница «Контакты» и футер                               |

### Поиск (экраны 10–11)

| Метод | Путь                                 | Что делает                                                                                |
| ----- | ------------------------------------ | ----------------------------------------------------------------------------------------- |
| GET   | `/search?q=&type=&page=&pageSize=10` | Страница результатов. `type`: `news`\|`project`\|`document`\|`page` (без параметра — все) |
| GET   | `/search/suggest?q=&limit=3`         | Живые подсказки в оверлее + `total` для ссылки «Все результаты»                           |

Ответ `/search`:

```json
{
  "items": [
    {
      "type": "news",
      "id": 1,
      "title": "В Оше открылся новый центр поддержки семей",
      "snippet": "Третий по счёту центр поддержки семей открылся…",
      "meta": "2026-07-03"
    }
  ],
  "counts": { "all": 14, "news": 8, "project": 3, "document": 3, "page": 0 },
  "page": 1,
  "pageSize": 10,
  "total": 14,
  "totalPages": 2
}
```

- `meta` зависит от типа: дата (news), `"active"|"completed"` (project), `format` + `sizeBytes` можно отдать отдельными полями для document.
- Подсветку совпадений фронт делает сам по `q` — спецразметка в `snippet` не нужна.
- «Вы искали» (недавние запросы) — localStorage на фронте, бэку не нужно.
- «Популярные разделы» в пустом оверлее — статика на фронте.
- Минимальная длина `q` — 2 символа, иначе `400`.

### Формы (экраны 12, 14)

| Метод | Путь             | Тело                                                       | Ответ                                                   |
| ----- | ---------------- | ---------------------------------------------------------- | ------------------------------------------------------- |
| POST  | `/feedback`      | `{ name, email, topic, message }` — модалка «Написать нам» | `201 { "id": 1 }` · `400` с `fields`                    |
| POST  | `/subscriptions` | `{ email }` — подписка в футере                            | `201` · повторный e-mail → `200` (идемпотентно) · `400` |

Валидация `/feedback`: все поля обязательны; `email` — формат; `message` ≥ 10 символов. `topic` — свободная строка (в макете это select, значения задаёт фронт).

## 4. Что поменяется на фронте при переходе с моков

Слой данных изолирован в `src/mocks/` — страницы менять почти не придётся. Отличия контракта от текущих моков (осознанные, «на вырост»):

| Сейчас в моках                  | В контракте                       | Действие на фронте         |
| ------------------------------- | --------------------------------- | -------------------------- |
| `date: '3 июля 2026'` (строка)  | `publishedAt: '2026-07-03'` (ISO) | утилита `formatDate()`     |
| `category: 'Проекты'` (строка)  | `{ slug, title }`                 | фильтры перейдут на slug   |
| `size: '2.4 МБ'`, `type: 'PDF'` | `sizeBytes`, `format`             | утилита `formatFileSize()` |
| `relatedIds` / `newsIds` (id)   | развёрнутые `related` / `news`    | убрать резолв по id        |
| `kind: 'Партнёр'/'Донор'`       | `'partner'/'donor'`               | словарь подписей           |

## 5. Вне скоупа v1

- Админ-панель и любые операции записи контента (раздел 5.1 ТЗ — отдельная задача; это API читает то, что она создаст).
- Аутентификация, личные кабинеты.
- Превью PDF в браузере (ждёт решения заказчика — пока только скачивание по `url`).
- Отдача изображений в разных размерах (resize/webp) — желательно, но не блокирует v1.
